# SAGE Summer Camp 2026

This repository contains the work, notes, and projects I completed during **SAGE Summer Camp 2026**. The camp focused on learning about edge computing, developing applications for the SAGE platform, and exploring how AI and data processing can be moved closer to where data is collected.

## Repository Contents

### Edge App Tutorial

The `edge-app-tutorial` folder contains the work completed while learning how to create, test, and publish an edge application using SAGE.

The tutorial covered the basic workflow for developing SAGE edge apps, including:
- Creating an edge application
- Building and testing the application
- Running the app on SAGE infrastructure
- Publishing an edge app

Tutorial reference:
https://sagecontinuum.org/docs/tutorials/edge-apps/creating-an-edge-app

### Classroom Notes

The `classroom-notes` folder contains notes taken during the different presentations and sessions throughout SAGE Summer Camp.

These notes include topics covered by speakers and instructors, including edge computing concepts, SAGE infrastructure, AI applications, and research projects using the platform.

### SAGE Bat Counter Project

The `project.md` file provides an overview of the project I worked on with Liam Fitzpatrick during the camp.

Our project focused on adapting an existing YOLO-based bat detection and tracking pipeline to run on SAGE edge computing resources. The goal was to explore how thermal video processing could be performed closer to the data source instead of relying on offline processing.

The project explored:
- Deploying computer vision workloads on edge devices
- Running YOLOv11 object detection with SORT tracking
- Processing thermal video data on SAGE nodes
- Creating a pipeline for real-time bat counting
